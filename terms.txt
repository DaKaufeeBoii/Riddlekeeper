1. HIGH-LEVEL ARCHITECTURE & PARADIGM TERMS
--------------------------------------------------------------------------------

• Neuro-Symbolic AI:
  - Definition: Combining deep neural networks (which excel at raw perceptual
    pattern recognition) with symbolic reasoning engines (which excel at exact
    logical deduction, search, and constraint satisfaction).
  - Presentation Soundbite: "We use a decoupled neuro-symbolic pipeline: neural
    networks handle perception and spatial routing, while exact symbolic algorithms
    solve combinatorial constraints without hallucination."

• Out-of-Distribution (O.O.D.) Size Extrapolation:
  - Definition: Training an AI model strictly on small problem dimensions (e.g.,
    5x5 grids) and testing its ability to solve much larger, unseen configurations
    (e.g., 8x8 and 10x10 grids) zero-shot without fine-tuning.
  - Presentation Soundbite: "Our primary research objective is size extrapolation —
    ensuring the model learns the invariant discrete solving algorithm rather than
    memorizing fixed grid coordinates."

• Spatial & Relational Reasoning:
  - Definition: The capability of an agent to understand 2D grid topology,
    coordinates, obstacle walls, reachability fields, and pairwise spatial
    dependencies between entities (agents, goals, boxes, pipe segments).
  - Presentation Soundbite: "Visual puzzles test spatial relationships — knowing
    not just where an object is located, but how its position constrains permissible
    subsequent actions."

• Sequential Decision-Making:
  - Definition: Generating a closed-loop sequence of discrete actions
    (a_0, a_1, ..., a_T) where each step transitions the environment state
    s_{t+1} = f(s_t, a_t) toward a verified goal condition.
  - Presentation Soundbite: "Unlike static classification tasks, puzzles require
    closed-loop sequential planning where a single suboptimal move can cause
    irrecoverable deadlocks."

2. GRAPH NEURAL NETWORKS (GNN) & ALGORITHMIC ALIGNMENT
--------------------------------------------------------------------------------

• Algorithmic Alignment (Xu et al., Dudzik et al.):
  - Definition: The theoretical principle stating that a neural network can learn
    and generalize an algorithm out-of-distribution if its individual computational
    steps (layers and aggregations) structurally map to the steps of that algorithm.
  - Presentation Soundbite: "According to the theory of algorithmic alignment,
    neural networks extrapolate out-of-distribution when their computational graph
    mirrors the recurrence steps of the target algorithm."

• Bellman-Ford GNN:
  - Definition: A recurrent Graph Neural Network whose node update rule mimics the
    Bellman-Ford unit-cost distance relaxation:
      d^(k)(v) = min( d^(k-1)(v),  min_{u in N(v)} (d^(k-1)(u) + 1) )
  - Presentation Soundbite: "Our GNN aligns directly with the Bellman-Ford
    relaxation step, enabling zero-shot 100% path optimality on 8x8 and 10x10 grids."

• Message-Passing Depth (K):
  - Definition: The number of recurrent message exchanges executed between
    adjacent nodes in the graph, set dynamically to K >= 2(H + W) >= diam(G).
  - Presentation Soundbite: "By dynamically scaling the message-passing depth K
    with the board diameter, information propagates across the entire grid
    regardless of size."

• Receptive Field Collapse:
  - Definition: Why standard Convolutional Neural Networks (CNNs) fail to generalize:
    convolutions rely on fixed 3x3 receptive fields and global pooling. As board
    dimensions scale up, distant goal signals fall outside the local receptive
    field, collapsing success rate from 20% to 10%.
  - Presentation Soundbite: "Standard CNN policies fail on larger grids because
    distant goal signals fall completely outside their fixed local receptive fields."

3. SYMBOLIC CONSTRAINT SATISFACTION SOLVERS (CSP)
--------------------------------------------------------------------------------

• Constraint Satisfaction Problem (CSP):
  - Definition: A mathematical formulation defined by a set of variables, domains
    of permissible values, and hard constraints that must all be satisfied
    simultaneously without conflicts.

• Minimum Remaining Values (MRV) Heuristic (Sudoku):
  - Definition: A fail-first heuristic in backtracking search that always selects
    the unassigned grid cell with the fewest remaining valid candidate digits.
  - Presentation Soundbite: "MRV prunes over 85% of redundant search branches,
    solving standard and hard 9x9 Sudokus in under 15 milliseconds."

• Bitmask Backtracking (N-Queens):
  - Definition: Tracking blocked columns, main diagonals (r - c), and anti-diagonals
    (r + c) as integer bitmasks, enabling O(1) bitwise conflict checks.
  - Presentation Soundbite: "Bitmask conflict propagation allows the N-Queens
    solver to verify non-attacking placements in constant time per candidate."

• Corner & Wall Deadlock Pruning (Sokoban):
  - Definition: Detecting irreversible states where a box is pushed into a corner
    or against an unbroken wall without a goal, and immediately pruning that search
    branch to prevent infinite loops.
  - Presentation Soundbite: "Deadlock detection prevents the A* search tree from
    exploding, pruning hopeless box placements before they consume memory."

• Hungarian Minimum-Matching Heuristic (Sokoban):
  - Definition: An admissible bipartite matching algorithm that computes the
    optimal sum of Manhattan distances between all boxes and goals.
  - Presentation Soundbite: "The Hungarian matching heuristic guarantees an
    admissible A* lower bound, guiding the search toward optimal push sequences."

• Dead-End Neighbor Validation (Flow Free):
  - Definition: Pruning any state where an unvisited empty cell is left with fewer
    than 2 open neighbors (or fewer than 1 for endpoints), which would make 100%
    board coverage mathematically impossible.
  - Presentation Soundbite: "Dead-end neighbor checking prunes dead paths early,
    ensuring all 25 cells of the 5x5 Flow Free board are completely covered."

• Rotational Invariance & Single Component Connectivity (Pipes / Net):
  - Definition: Formulating pipe tile orientations as a discrete 4-state rotation
    problem (0, 90, 180, 270 degrees) and verifying that the final configuration
    forms a single connected component using Breadth-First Search (BFS).

• Sequential String-to-Coordinate Mapping (Words / Wend):
  - Definition: Finding self-avoiding continuous letter paths across 2D character
    matrices matching target vocabulary lists using Depth-First Search with prefix
    pruning.

4. VISION, PERCEPTION & DETERMINISTIC RENDERING PIPELINE
--------------------------------------------------------------------------------

• Decoupled 3-Stage Pipeline:
  - Stage 1: Perception (Computer Vision / VLM reads screenshot into structured data)
  - Stage 2: Reasoning (Deterministic symbolic/neural solver computes exact moves)
  - Stage 3: Rendering (Graphics engine draws sub-pixel accurate solution overlay)
  - Presentation Soundbite: "We decouple seeing from thinking: the vision module
    only transcribes the scene, while mathematical solvers eliminate hallucinations."

• Local CV vs. Local Vision-Language Model (VLM):
  - Local CV: Ultra-fast OpenCV/Numpy pixel heuristics (< 0.05 seconds) for clean
    digital puzzle screenshots.
  - Local VLM: Local Ollama runtime (Qwen2.5-VL:3B or Moondream) for unformatted
    photos and real-world clippings, with zero cloud dependency.

• Pixel Hallucination:
  - Definition: Why Generative AI (DALL-E, Stable Diffusion) cannot be used to
    draw solutions: generative diffusion models invent numbers, distort lines, and
    break physical maze walls.
  - Presentation Soundbite: "Generative models hallucinate pixels. Riddlekeeper uses
    deterministic Pillow (PIL.ImageDraw) for 100% mathematically verified overlays."

• Adaptive Grid Bounding:
  - Definition: Estimating background colors from image corners and clustering cell
    densities to automatically crop out title headers, margins, and coordinate
    labels (A-H, 1-8).

5. EVALUATION METRICS & GENERALIZATION BENCHMARKS
--------------------------------------------------------------------------------

• In-Distribution (I.I.D.):
  - Benchmark tested on 5x5 grid dimensions matching the training distribution.

• Out-of-Distribution (O.O.D.):
  - Scale Tier 1: 8x8 grids (64 cells, 2.56x area expansion).
  - Scale Tier 2: 10x10 grids (100 cells, 4.00x area expansion).

• Success Rate (SR %):
  - Percentage of puzzle episodes where the agent successfully reaches the goal
    within the maximum allowed step cap (2 * H * W).
  - GNN: 100.0% on 5x5, 100.0% on 8x8, 100.0% on 10x10.
  - CNN Baseline: 20.0% on 5x5, collapsing to 10.0% on 8x8 and 10x10.

• Path Optimality Ratio (POR):
  - Formula: POR = (Steps Taken) / (Optimal BFS Shortest Path Length)
  - A ratio of 1.00x indicates a mathematically optimal path.
  - GNN: 1.00x (Perfect unit-cost shortest paths).
  - CNN Baseline: 25.8x to 40.7x (Fails and hits step caps).

• Search State Budget:
  - Hard cap on explored states (e.g., 5,000 states) to guard against combinatorial
    explosions and guarantee real-time termination with StateBudgetExceeded status.

6. CHEAT-SHEET: FREQUENT FACULTY & EXAMINER QUESTIONS
--------------------------------------------------------------------------------

Q: "Why did you use Graph Neural Networks instead of CNNs or Reinforcement Learning?"
A: "CNNs rely on fixed receptive fields and global pooling, which fail when the board
    size expands beyond training dimensions. Reinforcement learning tends to memorize
    state-action pairs. Graph Neural Networks operate over relational adjacency graphs,
    allowing message-passing depth to scale dynamically with board diameter."

Q: "Why not just feed the puzzle image to ChatGPT or an LLM directly?"
A: "LLMs predict the next token based on statistical word probabilities rather than
    formal logic. On combinatorial puzzles like Sokoban or Sudoku, LLMs frequently
    hallucinate invalid numbers or illegal moves. Our decoupled architecture uses
    multimodal perception strictly to transcribe the board and delegates solving
    to exact, verified algorithms with 0% reasoning error."

Q: "What is your novel contribution in this project?"
A: "Our contribution is twofold:
    1. We demonstrate that algorithmic alignment with the Bellman-Ford algorithm
       enables zero-shot size extrapolation on visual grid navigation (100% optimal).
    2. We integrate this neural navigator into a unified, extensible multi-puzzle
       framework covering six diverse spatial constraint families with deterministic
       visual explanation overlays."
